Numerically evolving the asymptotically-AdS$_4$ Einstein equations — the
Chesler–Yaffe scheme on a pseudospectral Chebyshev grid with Adams–Bashforth
time stepping — is accurate but expensive. This project asked whether a learned
model could shortcut the expensive part: predict the **entropy function of the
apparent horizon** directly from a compressed, ten-dimensional feature vector of
the initial data.

The answer was yes, and carefully so. The emphasis was as much on discipline as
on accuracy: strict train/validation/test splits, $k$-fold cross-validation, and
released code, so that the result is reproducible rather than anecdotal. It sits
squarely in the "scientific ML" register I care about — physics setting the
structure, machine learning doing the interpolation, and validation you can
trust.
